# VPS Xray Implementation Plan

**Goal:** 将现有双隧道项目重构为安全默认的 VPS 单核心部署。

**Architecture:** 启动脚本生成并检查配置后 exec Xray；Node 不处理代理流量。离线初始化和导出由零第三方依赖的 CLI 提供。

**Tech Stack:** Node.js 22+ 内置 crypto/test，固定 Xray 26.10.31，Docker Compose。

## Global Constraints

- 不使用 Cloudflare、Railway、手写代理解析和公网管理接口。
- 不生成真实用户凭证到跟踪文件，不覆盖已有秘密文件。
- 服务端私钥只用于服务端；每设备独立 UUID；公网只暴露 TCP 443。
- 在当前 checkout 的 refactor/vps-xray-reality 分支实现，用户可直接在 IDE 查看；不自动提交或部署。

## Task 1: 配置与离线 CLI

Files: `lib/config.js`, `scripts/manage.js`, `test/config.test.js`, `test/cli.test.js`, `package.json`。

Interfaces: `readConfig(env)` 校验；`buildServerConfig(config)` 返回 Xray JSON；`buildClientConfig(config, client)` 返回 Mihomo 对象；`buildVlessLink(config, client)` 返回 URI；CLI `init SERVER SNI [device...]`、`server PATH`、`export DIR`。

- [x] 编写并运行失败测试：必填项、UUID/密钥/域名/端口/重复设备校验，权限、覆盖拒绝、设备隔离、凭证不出现在 stdout/stderr。
- [x] 实现上述接口；生成 X25519 并派生公钥；服务端 RAW/REALITY/Vision、私网出站阻断；客户端 localhost、代理 DNS、不含 DIRECT 回退。
- [x] `node --test test/*.test.js`，9 项通过。
